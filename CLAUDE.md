## Project

Personal portfolio website for **Om Badade**, a product manager and builder based in Mumbai. Built as a Next.js App Router app with React 19, TypeScript, and a single hand-written stylesheet. The site is a single-page portfolio with section pages reachable from the sticky navbar.

## Tech stack

- **Next.js 16.3.6** (App Router — `app/` directory, no `pages/`)
- **React 19.2.8**, **TypeScript 5**, **ESLint 10** with `eslint-config-next` 16.3.6 (flat config in `eslint.config.mjs`)
- Styling: plain CSS in `app/globals.css` + `next/font` for Manrope (body), Plus_Jakarta_Sans (heading), JetBrains_Mono (mono)
- Icons: `lucide-react`, `react-icons/si`
- Animation: `framer-motion` (only in `app/template.tsx` page-transition wrapper)
- No test runner, no state-management library, no CSS framework

## Commands

All scripts are in `package.json`; run from the repo root.

```bash
npm run dev      # next dev — dev server at http://localhost:3000
npm run build    # next build (production build, also runs TS type-checking)
npm run start    # next start (serve the build)
npm run lint     # eslint (flat config via eslint.config.mjs)
```

There is no test command. TypeScript type-checking is folded into `next build` (no separate `tsc` step).

## Architecture

### Routing

- `app/layout.tsx` — root layout. Loads the three fonts, injects a `beforeInteractive` theme-init script (prevents flash), renders the fixed `.grid-bg`, `<Navbar>`, `{children}`, and `<Footer>`. Defines site metadata.
- `app/page.tsx` — homepage (`"use client"`). Hero, About, projects preview, skills preview, experience preview. Uses an `IntersectionObserver` `.reveal` animation pattern to fade sections in on scroll.
- `app/template.tsx` — wraps every non-root page in a `framer-motion` fade/slide-in transition.
- Section pages, each a single self-contained component in its own folder:
  - `app/projects/page.tsx` — project cards with category filter buttons (stateful, `"use client"`)
  - `app/skills/page.tsx` — skill columns (chips, server component)
  - `app/experience/page.tsx` — vertical timeline (server component)
  - `app/certificates/page.tsx` — certificate grid (PDF previews via `<object>`)
  - `app/contact/page.tsx` — contact link cards
- `components/Navbar.tsx` — sticky, blurred navbar with active-link highlighting (`usePathname`) and a light/dark theme toggle (`"use client"`).
- `components/Footer.tsx` — contact CTA + social icon links.

### Theming

- Theme is driven by `data-theme` on `<html>` (`"light"` | `"dark"`).
- **Default is light mode.** The `beforeInteractive` inline script in `app/layout.tsx` reads `localStorage` key `portfolio-theme`; if absent, falls back to `prefers-color-scheme`, with light as the final default.
- CSS variables: `:root` defines the light palette; `:root[data-theme="dark"]` overrides for dark mode. All components consume these variables — never hardcode colors.
- The Navbar toggle writes the user's choice back to `localStorage`.
- `prefers-reduced-motion` disables all transitions/animations.

### Styling conventions

- All styles live in `app/globals.css` using CSS variables.
- Layout primitives: `.wrap` (max-width 1080px, centered, 28px side padding), `.page-section`, `.sec-head` + `.sec-tag`, `.btn` / `.btn-primary` / `.btn-ghost`.
- Responsive breakpoints: 820px (hero grid), 760px (navbar links hide, grids collapse), 700px (stat strip), 640px (wrap padding), 520px (skill grid single column).

### Path alias

`@/*` maps to `./*` (see `tsconfig.json` paths). Import shared components as `@/components/Navbar`, etc.

### Public assets

`public/` holds images, logos, PDFs (resume, certificates), and favicons. Images are referenced directly (e.g. `/ProfilePic.png`) and optimized at build time via `next/image`.
